## 💻 How to Run the C Programs

To run any of the `.c` files locally, follow these steps:
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Compile the file (using GCC):**
   ```bash
   gcc filename.c -o output
   ```
3. **Execute the program:**
   ```bash
   ./output
   ```
